## 적용 자료

- preview.html: 실제 PNG와 개별 부품 미리보기.
- manifest.json: 원본 크기·투명 픽셀 수·실측 각 부품 좌표.
- ReplacementAssets.luau: Roblox ImageRectOffset/ImageRectSize 매핑. 업로드 asset ID는 비워 두었다.
- COVERAGE.md: 현재 화면15종과 부품 대응/적용 순서.
- prompts.md: 실제 생성 프롬프트6개 및 컨트롤 투명 영역 정리 프롬프트.

글자·가격·타이머·키 문자·수치는 이미지에서 분리했다. 희귀도 카드에는 고유 미사일 그림을 굽지 않았으므로 실제 보유 미사일 이미지/ViewportFrame을 얹어 쓴다. 플레이 중앙 시야·모바일 조작부·전투 버튼 safe area는 적용 단계에서 조정한다.

## 좌표·검증 한계

새 투명 아틀라스5개에서 부품 수12/12/12/8/16과 실제 알파를 확인. 등간격 셀을 가정하지 않고 alpha>=32/255 연결 영역+2px 여백으로 실측했다. 분리된 아이콘 조각은 중심이 같은 칸에 속하는 조각끼리 합쳤다. 기존12종은 검증된362×362 셀을 사용했다.

선택 테두리 중심 샘플의 alpha 최대2/255, alpha>64 픽셀0. 일부 가장자리에 매우 옅은 알파 프린지가 남을 수 있다. 9-slice 경계는 고정 확정하지 않았으며 실제 크기·Roblox 리샘플링에서 확인해야 한다. 모바일 렌더/터치 영역·글꼴 검증은 미실행.

원본/기존 시안은 보존하고 새 replacement-kit 폴더에 저장. 기존 UI 기능·서버 판정·가격·화면 코드는 변경하지 않았다.
