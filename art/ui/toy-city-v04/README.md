# ProjectMS UI v04 — 파랑·빨강·노랑 입체 UI

2026-11-14. 사용자 요청: 첨부 HUD와 Pinterest 3개 레퍼런스 같은 굵은 외곽선·입체 아이콘·짧은 한글 UI. 빨강/노랑도 적극적으로 사용하고 아이콘을 재제작.

## 제작물

- ui-style-sheet-v04.png — 1536×1024. 게임 HUD·파랑/노랑/빨강 버튼·보관함·연구/패시브 창·색상표 시안.
- icons-atlas-v04.png — 1448×1086, RGBA 실제 투명 PNG. 4열×3행, 칸마다362×362.
- manifest.json / UIAtlas.luau — 각 아이콘 ImageRectOffset/ImageRectSize. 업로드 전이라 asset ID는 비워 두었다.
- preview.html — UI 시트와 12개 아이콘을 원본 PNG로 확인하는 로컬 미리보기.
- prompts.md — 내장 ImageGen에 전달한 실제 프롬프트2개.

아이콘 순서: 상점 / 미사일 / 도감 / 연구 / 제작 / 기지 / 차고 / 강화 / 코인 / 연구자료 / 집중 발사 / 설정.

## 적용 기준

굵은 남색 외곽선, 상단 하이라이트·하단 돌출 그림자, 큰 그림과 짧은 글자. 파랑 기본 행동, 노랑 강화/보상, 빨강 출격/집중 공격/닫기. 전투 중앙을 비우고 메뉴를 가장자리로 모은다. 그림 아이콘과 버튼 배경은 분리해서 적용하고 한글·수치·상태는 Roblox 네이티브 UI로 작성한다.

UI 시트의 재화/가격/타이머·연구 항목·잠금 상태는 시각 예시이며 현행 밸런스나 신규 기능 확정값이 아니다. 패시브·상점 등은 이 이미지로 구현됐다는 뜻이 아니다. 시트와 아틀라스의 일부 아이콘 세부 묘사는 다르므로 실제 적용 시 아틀라스 원본을 우선한다.

## 검증

내장 ImageGen 생성2개를 시각 확인: 굵은 테두리·한글 주요 이름·세 가지 주요색·12개 주제 확인. 아틀라스32bit ARGB/투명 픽셀 확인, 362/724/1086 세로·362/724 가로 내부 경계의 불투명 픽셀0. 원본은 generated_images에 보존하고 새 v04 폴더에 복사. 기존 v01/v03 유지.

이번 작업은 시트·아이콘 제작이다. Studio/UI 코드 변경·업로드·Play 검증은 수행하지 않았다. Claude가 Studio 맵 색감 작업 중이라는 TODO를 확인했고 해당 작업에 개입하지 않았다.
