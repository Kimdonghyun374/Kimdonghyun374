# ProjectMS UI — 최신 방향: Simple Sci-Fi v02

사용자 수정 방향: 아주 단순한 UI, 메뉴 기호와 미사일·탈것 개별 UI 이미지 등록, 나머지는 Roblox 기본 UI로 제작. Pet Simulator 99의 읽기 쉬운 구조를 참고하고 미사일 게임에 맞는 단단한 SF 인상으로 조정.

이 폴더 이름의 v01은 작업 묶음 버전이며 최신 디자인 시트는 v02다. 앞서 만든 16종 입체 토이 아이콘은 사용자 방향과 맞지 않아 채택/업로드하지 않았다.

이번 시트는 내장 ImageGen으로 생성한 디자인 제안이다. 게임에 바로 넣는 통짜 PNG가 아니다. 패널/버튼/글자/막대는 Roblox에서 만들고 필요한 단순 메뉴 기호와 모든 이용 가능한 미사일·탈것의 개별 이미지를 별도로 제작해 업로드한다. 현재는 시트 검토 단계이며 새 아이콘 파일이나 에셋 ID가 준비된 상태로 간주하지 않는다.

UI 시트의 숫자·희귀도·탭은 예시다. 실제 인벤토리는 개별 item.id 기반이므로 x12 같은 중첩 수량 표기를 그대로 기능화하지 않는다. RIDE 기호가 바퀴 달린 보드처럼 표현됐으므로 실제 아이콘 제작 시 바퀴 없는 호버보드로 정리한다. 게임 배경/캐릭터는 UI 배치 설명용, 모델 교체 지시가 아니다.

2026-11-09 실제 Studio의 UI 생성 스크립트와 Enabled 상태를 읽고 인수인계에 반영. 초기 토이 테마 모듈의 임시 생성 테스트는 했지만 새 디자인용 배포 코드로 제공하지 않는다. Studio 게임 변경, Save/Publish, 이미지 업로드 없음.

사용자가 C:\ProjectMS\art\ui\toy-city-v01 업로드 폴더 허용 완료라고 응답했음. 실제 업로드 성공 여부는 아직 검증하지 않음.

사용자 추가 방향: 장비 카드의 미사일·탈것은 모두 개별 이미지. 현재 시트의 흰 실루엣은 자리 표시이며 최종 장비 이미지가 아님. 월드 3D 모델은 별개.
