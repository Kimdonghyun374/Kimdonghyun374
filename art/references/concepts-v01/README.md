## 공통 방향
링 광장, 8개 기지, 개인 진격 대로, 주택→상업→연구 구역, 거대 장벽 보스, 미사일 수집·제작·파괴·부품 회수. 이미지의 기지 수·도로 각도·건물 수는 정확한 배치도가 아니며 실제 제작에서는 기획서 수치와 Studio 매핑을 따릅니다. 보스 및 추가 구역은 제안 모습입니다.

## 추천
첫 월드는 01의 밝고 단순한 가독성을 기본으로 삼고, 02의 조립형 제작기와 미사일 랙을 결합하는 방향을 추천합니다. 순수한 한 안을 고른다면 01부터 검증하기 쉽습니다. 02와 03은 각각 산업/연구 월드의 후속 테마로도 활용할 수 있으나 아직 확정하지 않았습니다.

## 폴더 사용
이 폴더는 AI 생성 제안 이미지용입니다. 외부 참고 이미지는 별도 하위 폴더에 출처·사용 조건과 함께 보관합니다. 승인된 모델/텍스처 원본은 이 폴더와 구분합니다. 선택 후 기지·제작기·미사일 랙·주택을 동일한 스타일로 개별 상세화합니다.

생성 방식: 내장 ImageGen. 실제 사용한 전체 프롬프트는 prompts.md 참고. 원본 PNG를 변형 없이 복사했습니다.
