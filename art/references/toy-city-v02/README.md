## 제작 기준
- 환경: 링 광장은 사회적 공간, 대로는 개인 도시 진행 공간. 후반 도시의 높은 실루엣으로 화력 성장을 보여준다.
- 건물: 층·창문·지붕 모듈을 재사용한다. 장식은 파괴 판정과 구분한다. 이미지의 스케일·기지 개수·도로 각도는 배치 명세가 아니다.
- 미사일: 색만이 아니라 몸통·날개 실루엣으로 구분한다. 랙 S/M/L/XL은 크기 비교이며 슬롯 개수·해금 정책이 아니다. 최종 게임 수량과 배치는 Config를 따른다.
- UI: 목표 하나, 부품, 선택 대상 체력, 장착/재장전, 집중 발사를 우선한다. 모바일에서 이동·점프·집중 발사 영역을 분리한다. 이미지 속 영어·수치·BASIC/BURST/HEAVY/CLUSTER/EMP/DEMO는 임시 표현이며 신규 능력 구현을 승인한 것이 아니다. 일시정지 아이콘은 멀티플레이 서버 정지 기능을 의미하지 않으며 최종 UI에서는 제거하거나 메뉴로 대체한다.
- 이펙트: 짧은 발사 연기 → 얇은 궤적 → 국소 착탄 → 단계별 손상 → 블록 붕괴 → 금색 부품 회수. LOW FX는 시각 제안이며 성능 검증 결과가 아니다.
- 손상 비율: 시트의 70/30%와 타이밍은 예시다. 현재 코드와 이력의 75/50/25% 설정을 바꾸지 않았다. 실제 연출시간·피해 판정은 서버 계약과 맞춰야 한다.

## 검수·출처
내장 ImageGen 사용. 원본 01-toy-city.png를 스타일 참조로 사용했으며 외부 이미지 수집은 하지 않았다. 6장 시각 검토, 미사일 랙의 숫자/개수 불일치를 발견해 숫자를 S/M/L/XL 크기 표기로 수정했다. 이미지별 원본 SHA256 복사 검증. 생성 프롬프트와 수정 프롬프트는 prompts.md에 보관.

모든 PNG는 콘셉트 참고용이며 실제 3D 모델·UI 구현·투명 파티클 텍스처 또는 스프라이트 시트가 아니다. 다음 제작 단위는 주택 1개 + 제작기 1개 + 기본 미사일 1개 + 착탄 효과 1개를 동일 스타일로 구현하여 게임 화면에서 비교하는 것.
