## 적용 기준과 한계

화이트·밝은 회색 바탕, 파랑 중심에 빨강·노랑·초록 포인트, 부드러운 푸른 낮빛. Google 로고/브랜드 사용 아님.

이 이미지는 모델 제작 참고용이며 실제 Studio 화면·정확한 배치도·수치 명세가 아니다. 광장 기지의 정확한 8개 배치와 길 폭은 레벨디자인 문서를 따른다. 건물 시트의 키·실제 크기 표시는 생성 예시이며 측정값이 아니다. 75/50/25% 손상 임계값은 현행 문서 기준, 실제 구멍과 붕괴 형태는 추가 아트 제안이다.

UI 수치와 배치는 예시. 대형 조준 표시와 옥상 발사대는 실제 구현 확정이 아니다. 미사일 디자인 01~05는 확정 희귀도 매핑이 아니며 랙 S/M/L/XL은 크기 비교다. 하단 부품 아이콘은 제작 컨셉이며 개별 부품 조립 기능을 승인한 것이 아니다.

탈것 4종은 비교 제안. 호버보드부터 시작하는 방향을 시각화했으나 구매 가격·해금 순서·성능은 미확정. 광장의 버기만 호버보드로 교체했다. 버기 게임 코드·GDD·Studio는 수정하지 않았다.
