# AI와 함께 배우는 ProjectMS — 첫 학습 단위

목표: 전체 코드를 외우기보다 핵심 흐름을 설명하고 작은 수정 결과를 검증할 수 있기.

1. Explorer: Model/Part/Script/LocalScript/ModuleScript 위치와 역할 찾기.
2. Luau: 변수, 함수, if, table, 이벤트를 실제 짧은 코드에 연결하기.
3. 첫 실습: 호버보드 프로토타입이 생기면 속도 설정 한 곳을 찾고 변경 전 결과 예측, 값 변경, Play에서 비교, 되돌리기. 아직 호버보드 구현이 없으므로 존재하지 않는 파일명을 가정하지 않는다.
4. Vector3와 CFrame: 방향/속도 벡터와 위치/방향 변환의 차이를 작은 이동 실험으로 이해하기.
5. 클라이언트/서버: 입력·카메라·기울기 연출과 구매·보유·저장·이동 검증의 책임 분리.
6. 구매 한 번의 흐름 추적: 버튼→요청→서버 검증→차감/지급→응답/UI→저장. 실패/중복 요청도 확인.

매일 30분: 10분 읽기, 10분 직접 수정, 10분 결과를 자기 말로 설명. AI에게 먼저 완성 답을 요청하기보다 자신의 예측을 적고 검토를 요청하기. AI가 맡긴 변경 중 작은 하나는 본인이 직접 시행.

직접 이해할 부분: 화폐 증감, 구매/업그레이드 검증, 피해·보상, 저장, Remote 요청. AI에게 초안을 맡길 부분: 반복 배치, UI 꾸미기, 문서 정리, 아트 변형. 테스트 결과와 사용자 경험 판단은 직접 확인한다.
