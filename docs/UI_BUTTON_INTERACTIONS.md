# 버튼 인터랙션 구현 명세 — Claude 인수인계

기준일: 2026-11-15 KST. 사용자가 Codex의 아래 인터랙션 제안을 승인하고 Claude가 알 수 있게 전달 요청함.
이 문서는 구현할 요구사항이며, 아직 구현·Play 검증이 완료됐다는 뜻이 아니다.

## 현재 구현에서 유지할 것

- Studio Place 122289987934213 Edit가 기준. 작업 시작 시 최신 소스와 다른 에이전트의 Studio 사용 여부 확인.
- 최신 Claude 변경: RPG 장착 버튼은 PC·모바일 모두 화면 아래 중앙, 숫자 1 / 숫자패드 1 키로 장착·해제. 예전 G 키·왼쪽 아래 RPG 배치로 되돌리지 않는다.
- PC는 클릭으로 RPG 발사, 별도 발사 버튼 없음. 모바일은 RPG 장착 중에만 점프 버튼 주변에 발사 버튼 표시.
- 현재 HudLayout의 배치·화면 배율·안전 여백과 UIAppearance/UIImages의 이미지·글자 대비·Global ZIndex 보정을 유지.
- 구매/판매/장착/발사·서버 승인·재사용 시간·경제 규칙을 바꾸지 않는다. 관리자 흑백 UI는 이번 컬러 효과 적용 대상에서 제외.

## 공통 인터랙션 — 사용자 승인 방향

| 상태 | 시각·소리 반응 |
| --- | --- |
| PC 호버 | 아이콘만 4% 확대, 테두리를 살짝 밝게. 모바일에는 호버 상태를 남기지 않음 |
| 누르는 동안 | 버튼 그림을 93% 크기로 줄이고 아래로 2px 이동 |
| 정상적으로 손을 뗌 | 짧게 튕기며 원래 크기로 복귀, 클릭음 1회 |
| 사용 불가 | 회색 상태 유지. 누르면 해당 거절 이유를 짧게 표시 |
| 실행 성공 | 작은 반짝임·확인음. 구매·발사 성공은 실제 승인/상태 변경을 받은 뒤 표시 |

- 핵심: 클릭·터치 판정 영역은 고정하고 내부 그림만 움직인다. HudLayout이 배치한 루트 버튼에 애니메이션 UIScale/Position을 직접 적용해 판정 영역을 줄이지 않는다.
- 버튼 전체 눌림과 아이콘 호버를 분리해 중첩 배율이 누적되지 않게 한다. 텍스트는 읽을 수 있는 크기를 유지한다.
- 포인터가 밖으로 나가 취소됐을 때는 활성화/성공음 없이 복귀. UI 닫힘·숨김·장비 해제·입력 취소·화면 회전 시 눌린 상태를 반드시 정리.
- 빠른 연타·호버 반복에서 기존 Tween을 취소하고 기준값으로 복귀. 이벤트 중복 연결, 영구 RenderStepped 연결 누적, 아이콘 깜박임 방지.
- 기존 UIAppearance의 normal/pressed/disabled 스프라이트와 MouseButton1Down/Up/Leave 처리를 먼저 확인해 효과가 두 겹으로 붙지 않도록 통합.
- 클릭음/확인음은 기존 GameSounds를 사용. 이미 상태 처리에서 소리를 내는 경우 중복 재생하지 않음. 최근 MasterVolume=3 변경을 고려해 음량을 추가로 올리지 않는다.

## 버튼별 연출

1. 집중 발사
   - 실제 사용 준비 완료 시 금색 테두리를 천천히 밝게/어둡게 표시.
   - 발사 승인 후 짧은 섬광, 기존 충전 게이지 상태로 전환.
   - 미사일 없음·충전 중·사망 등 사용 불가 때 준비 완료 효과를 켜지 않는다.
2. RPG 장착
   - 장착 상태가 실제로 바뀌면 아이콘이 한 번 튀고 체크 표시가 나타남. 해제하면 체크 제거.
   - 숫자 1 키와 버튼 클릭 모두 같은 상태 연출 사용. 매 프레임 장착 연출을 반복하지 않는다.
3. 모바일 RPG 발사
   - 누르면 짧은 총구 섬광. 실제 발사 상태와 맞는 버튼 둘레 재사용 대기 게이지.
   - 기존 재사용 시간/서버 승인 정보를 재사용. 필요한 서버 승인 정보가 없다면 최소 동기화 경로를 확인하고, 거절된 발사를 성공처럼 연출하지 않는다.
   - 해제 시 버튼과 대기 연출을 정리. 재장착/회전으로 쿨다운 표시가 잘못 초기화되지 않게 함.
4. 미사일·탈것 메뉴
   - 공통 눌림 효과와 함께 해당 창이 약간 작게 시작해 원래 크기로 확대되며 등장.
   - 레이아웃/화면 맞춤용 UIScale과 연출용 배율을 분리. 닫기 및 연속 열기에서 팝업 크기가 누적 변형되지 않음.

## 구현 순서

공통 눌림 효과 → RPG 장착 상태 전환 → 집중 발사 준비 효과 → 모바일 RPG 쿨다운 → 메뉴 창 등장.
튜닝 시작값 제안(고정 요구 아님): 누름 0.07~0.09초, 복귀 0.12~0.18초, 창 등장 0.15~0.2초. 짧고 가볍게 조정.
새 공통 모듈이 필요하면 기존 UIAppearance와 역할이 겹치지 않게 구성. 현재 버튼 이벤트/RemoteEvent 연결은 보존.

## 완료 기준

- PC 마우스·키보드(집중 발사 F, RPG 1), 모바일 터치/드래그 이탈/연타, 가로·세로 전환 확인.
- 활성/비활성, 장착/해제, 충전/준비, 창 열기/닫기에서 시각 상태가 실제 게임 상태와 일치.
- 버튼 그림이 움직여도 터치 영역과 HudLayout 기준 위치는 변하지 않음. 중복 효과음 없음.
- 모든 바뀐 UI의 StarterGui.UIPreview 사본 갱신, 팝업은 Enabled로 켜서 확인 가능하게 유지. EditPreviewOnly·RemoveInPlay 보존.
- Studio 백업 후 UpdateSourceAsync + Source, 편집기 일치 확인. Play 검증 후 Edit 복귀·임시 러너 제거, Save/Publish 하지 않음.
- 검증한 기기/입력과 미검증한 실제 휴대폰을 구분해 HISTORY/TODO 기록, 커밋·푸시.
